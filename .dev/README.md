# `.dev/` — capa de coordinació

Res d'ací dins s'executa. És la memòria del projecte: el que sabem, el que estem fent
i el que hem decidit, perquè cap sessió comence de zero ni repetisca una discussió tancada.

```
.dev/
  plans/          un fitxer per feina de més d'una sessió. Es tanca, no s'esborra.
  memories-log/   un fitxer per sessió. Què s'ha decidit, què queda obert.
  archive/        material històric o d'altres projectes. No és font de veritat.
  skills/skill-tot-se-sap/
    SKILL.md      índex del coneixement
    refs/         QUÈ hi ha construït, ref a ref
```

**La separació que ho sosté:**

| Carpeta | Contesta | Temps verbal |
|---|---|---|
| `docs/` | per què el joc és així | intemporal |
| `refs/` | què hi ha construït | present |
| `plans/` | què estem fent i per què | futur → passat |
| `memories-log/` | què va passar | passat |

Si una cosa cap en dos llocs, va al de més amunt de la taula i les altres l'enllacen.
