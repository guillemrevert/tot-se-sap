# Memòria de sessions

Una entrada per sessió de treball: `AAAA-MM-DD-nom-curt.md`. **Curta.** Si passa de
40 línies, el que hi sobra probablement havia d'anar a un ref o a un pla.

No és un diari ni un changelog. Serveix per a una cosa sola: que la sessió següent
sàpiga **què es va decidir i què va quedar obert** sense llegir-se el codi ni el xat.

## Plantilla

```markdown
# AAAA-MM-DD — <títol>

## Què s'ha fet
Llista curta. Fitxers tocats.

## Decisions preses
Numerades. Amb el motiu, no només la decisió.

## Què queda obert
El que la sessió següent ha de resoldre. Enllaç a refs/07-decisions-obertes.md.

## Trampes trobades
Coses que van sorprendre. Açò és el que estalvia temps de veres.
```
